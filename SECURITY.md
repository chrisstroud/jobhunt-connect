# Security

Report a vulnerability privately through GitHub's private vulnerability reporting on this repository, or through the contact on
https://jobhunt.app/support if you cannot use GitHub. Please do not open a public issue for a vulnerability. We aim to acknowledge a report within three business days.

This repository holds documents and snippets only and no credentials. If you find a token, key or password in it, report it the same way.
The security policy for the JobHunt service will be at https://jobhunt.app/security once it is published.
